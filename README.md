# newfire.mx

Sitio estático en español (raíz) e inglés (`/en/`), publicado con GitHub Pages. Diseño basado en la página anterior hecha con Aida (one.com).

- Agregar un video: añade su ID de YouTube al inicio de la lista en `assets/content.js`.
- Agregar un recurso: añade una fila a la lista `RES` en `build.py` y ejecuta `python3 build.py`.
- Cambiar textos o páginas: edita `build.py` y ejecuta `python3 build.py`.
